> **统计周期：2026 年 11 月 7 日—11 月 13 日（北京时间）**

## 🔥 本周热点

1. **Gemini 4 形成“深度推理 + 高效执行”的模型分工** — Google 正式开放 Gemini 4 Carbon，并发布面向日常编码和 Agent 工作流的 Hydrogen；Antigravity Orchestrator 会在同一会话中动态切换模型。Google 称 Hydrogen 在 Terminal-Bench 4.1 得分 57%、相较 Gemini 3.8 Flash 的 18.2% 提升逾三倍，编排后平均少用 24% 配额、快 19%；均为 Google 厂商 benchmark/声明。[Hydrogen](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/) · [Carbon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)

2. **AlphaProof Code 把 AI Agent 带进大规模形式化验证** — Google DeepMind 表示，其多 LLM Agent 框架在专家参与下，用 Lean 对 Signal 核心加密协议代码建立了约 300 万行证明；官方称这是首次以如此深度形式化验证广泛部署的加密协议实现。成果与“首次”均属 Google 厂商研究声明，但让“生成代码”之外的机器可验证证据成为新方向。[Google DeepMind](https://deepmind.google/blog/introducing-alphaproof-code/)

3. **AlphaGenome 2 将变异影响预测推进到具体细胞类型和状态** — 新一代 DNA 序列模型不再只看组织平均值，而是预测遗传变异如何影响数百种人类细胞类型；它承接覆盖人类基因组约 90 亿种单碱基变化的 AlphaGenome Atlas，目标是帮助研究者定位疾病的细胞驱动因素。性能提升属于 Google 厂商研究声明，不能替代实验与临床验证。[Google DeepMind](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)

4. **通用机器人从实验室任务走向产线概念验证** — Gemini Robotics 2.5 是 Google 最新视觉—语言—动作模型，官方称已覆盖 200 多项任务；在 Mercedes-Benz 产线概念验证中，Apptronik Apollo 2 人形机器人分拣汽车部件成功率达 96%。该成功率与能力描述均为厂商测试/声明，真实部署仍需考察场景分布、故障恢复和安全边界。[Google DeepMind](https://deepmind.google/blog/gemini-robotics-2-5-accelerates-real-world-physical-intelligence/)

5. **AI 基础设施开始为“等待型、可恢复”的 Agent 原生设计** — NVIDIA 将 Agent Substrate 捐入 CNCF Sandbox；它以少量温热 Kubernetes Worker Pod 复用大量会话，并检查点保存空闲 Agent 的内存与文件系统。官方声称密度可达标准容器的 10 倍，这是 NVIDIA 厂商 benchmark/声明，但其架构直指长时 Agent 的成本、冷启动与状态保存痛点。[NVIDIA](https://developer.nvidia.com/blog/agent-substrate-advancing-kubernetes-for-agents-at-scale/)

## 🛠️ 新工具 / 产品发布

- **Gemini Decisions API** — 面向工具选择、策略检查、模型路由和上下文评分等封闭决策，一次可对文本、图像、音频、视频或 PDF 提出最多 1,000 个判断问题并返回置信度。Google 声称端到端延迟 150–250 ms、价格为每百万输入 token 0.10 美元且不收输出 token，均属厂商声明。[Google](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)
- **Google Flow 新工具** — Character Poster、Character Arc 等五款创作工具进入 Flow，重点不再只是生成单个镜头，而是维持跨年龄角色一致性、将手机素材整理为成片并加速视觉预制作。[Google](https://blog.google/innovation-and-ai/models-and-research/google-labs/new-google-flow-tools/)
- **Agent Substrate** — 开源、零信任的沙箱 Agent 运行时，可在 Kubernetes 中暂停、迁移和恢复包含内存及文件系统状态的会话，并与 NVIDIA Dynamo、KAI Scheduler 协作。[NVIDIA](https://developer.nvidia.com/blog/agent-substrate-advancing-kubernetes-for-agents-at-scale/) · [GitHub](https://github.com/agent-substrate/substrate)
- **Langfuse AI Gateway** — Langfuse 主仓库中的开源 Rust 网关项目，为 LLM 调用提供集中路由与可观测性入口，适合需要统一追踪多模型请求的团队；项目仍应以仓库文档和版本状态为准。[GitHub](https://github.com/langfuse/langfuse/tree/main/ai-gateway)
- **Chap by ChatPanel** — 在浏览器、桌面或终端运行的本地优先助手，可从 Zoom、Meet、Teams、Webex 的实时字幕记会议笔记，无需机器人入会；支持本地模型、20 多种云 API 与 MCP，并在设备端匿名化敏感字段。[项目页](https://chatpanel.net/) · [GitHub](https://github.com/chatpanel/chatpanel)
- **ThunderPhone v3 / Zeus** — 面向语音 AI 的 Agent harness，尝试让 Agent 直接处理电话任务、工具调用与对话控制，降低传统 ASR—LLM—TTS 三段流水线的误差和延迟；效果描述来自厂商发布，需在真实电话环境独立验证。[ThunderPhone](https://thunderphone.com/blog/introducing-zeus)
- **Mintigate Demo** — 离线 CLI 演示编码 Agent 的变更作用域、审批边界和审计记录；仓库明确使用模拟 Agent、没有在线模型，更适合作为控制层设计样例而非成品 Agent。[GitHub](https://github.com/MintCoderpro/mintigate-demo)
- **PARDIG 与 SatWeave** — Google DeepMind 开放支撑其天气模型的降水与卫星基础数据集，供研究者开发天气、水文和气候应用。[Google DeepMind](https://deepmind.google/blog/opening-the-datasets-behind-our-ai-weather-models/)
- **Gemini in Chrome** — Chrome 侧边栏内可直接总结当前网页、比较商品或解释复杂内容，减少跨标签复制上下文。[Google](https://blog.google/innovation-and-ai/products/gemini-app/research-with-gemini-in-chrome/)
- **Google Intelligent Eyewear** — Google、Samsung 与 Warby Parker、Gentle Monster 合作的 Gemini 智能眼镜开放预订，支持免手持实时辅助；官方标称约 41 克、最长 9 小时续航，起价 395 美元。[Google](https://blog.google/innovation-and-ai/technology/xr-ar/google-intelligent-eyewear-collections-pre-order/)

## 📊 模型更新

- **Gemini 4 Hydrogen** — 面向高频编码与 Agent 执行，提供 100 万 token 上下文，统一价格为每百万输入/输出 token 1.50/7.50 美元，并进入 AI Studio、Gemini API、Gemini app、Search 与 Antigravity。Artificial Analysis 指数及 Terminal-Bench 数据来自 Google 发布，应视为厂商 benchmark/声明。[Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)
- **Gemini 4 Carbon** — 面向复杂、多步编码调试、网络安全和开放式科学研究，API 初始价格为每百万输入/输出 token 2/10 美元；Google 宣称其在 CursorBench 4.0、WANDR 和 AutomationBench 排名第一，属于厂商 benchmark/声明。[Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)
- **Gemini Decision 1** — 不逐 token 生成答案，而在一次前向计算中为候选选项打分，原生支持多模态、是非/多选/有序量表三类决策。延迟、校准和“近 5 倍便宜”等均为 Google 厂商 benchmark/声明。[Google](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)
- **Gemini Robotics 2.5** — 强化机器人灵巧性、可靠性与物理安全可控性，并新增针对机器人越狱的安全评测；200 多项任务和 96% 产线成功率均为 Google 厂商测试/声明。[Google DeepMind](https://deepmind.google/blog/gemini-robotics-2-5-accelerates-real-world-physical-intelligence/)
- **AlphaGenome 2** — 从组织层预测下沉到单细胞类型与状态，尝试连接 DNA 变异、基因调控和疾病机制；预测结果应作为研究假设与候选排序工具，而非直接临床结论。[Google DeepMind](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)

## 💡 趋势观察

- **单模型包办一切正在让位于“协调者—执行者—验证者”组合**：Carbon 与 Hydrogen 的动态切换、并行隔离工作区和对抗验证器，都表明成本、速度和推理深度会按任务阶段调度，而不是固定选一个最强模型。
- **输出的终点从自然语言答案变成可验证对象**：AlphaProof Code 交付形式证明，Decisions API 交付概率和置信度，Agent 工具保留审计边界；企业采纳越来越依赖可检查、可回放的证据。
- **Agent 基础设施正在补齐操作系统能力**：会话检查点、沙箱、资源调度、调用追踪和审批层从应用插件升级为底层设施，长时运行与高密度复用将成为生产 Agent 的关键工程指标。
- **AI for Science 正从模型发布扩展为数据与工作流生态**：AlphaGenome 2、PARDIG、SatWeave 以及形式化验证框架显示，专用模型、开放数据、人类专家和确定性工具的闭环，比单纯扩大通用聊天模型更接近科研落地。
- **环境智能继续向浏览器、眼镜和机器人分流**：同一类多模态能力同时进入屏幕侧边栏、可穿戴设备和机械执行器，隐私提示、物理安全与故障降级会随界面消失而变得更重要。
