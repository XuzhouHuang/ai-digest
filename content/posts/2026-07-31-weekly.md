## 🔥 本周热点

1. **DeepSeek V4 Flash (0731) 发布** — DeepSeek 上线 V4-Flash，主打极致性价比与推理性能，社区在 HN 上讨论热度爆表（500+ 分、249 评论）。被视为本周对性价比格局冲击最大的一次更新。<https://api-docs.deepseek.com/updates/> · 性能分析：<https://artificialanalysis.ai/models/deepseek-v4-flash-ga>

2. **Moonshot Kimi 基于阿里 2 万张 Nvidia 集群训练** — Bloomberg 披露 Moonshot 最新 Kimi 模型建立在从阿里巴巴获取的 2 万张 Nvidia 芯片集群之上，凸显中国大模型算力供给的新路径。<https://www.bloomberg.com/news/articles/2026-07-31/moonshot-s-kimi-built-on-20-000-nvidia-chip-cluster>

3. **GitHub Stacked PRs 进入公测** — GitHub 正式上线 Stacked Pull Requests（堆叠式 PR），开发者工作流迎来重大改进，HN 750+ 分登顶。<https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/>

4. **GPT-5.6 Sol 攻破 Maxwell 猜想** — 一篇 arXiv 论文显示 GPT-5.6 Sol 给出了证明 Maxwell 猜想为假的解答，成为「AI 参与前沿数学」的又一标志性案例。<https://arxiv.org/abs/2607.27197>

5. **Google：AI 让 Chrome 漏洞修复效率翻数倍** — Google 表示仅 6 月修复的 Chrome 安全漏洞就超过过去两年总和，主要归功于 AI 辅助漏洞挖掘。<https://blog.google/security/chrome-stronger-with-every-update/>

## 🛠️ 新工具 / 产品发布

- **Shared Memory Graph (MCP)** — 面向 Claude 与 ChatGPT 的共享记忆图谱，基于 MCP 协议打通跨模型上下文。<https://uml.gpmai.workers.dev>
- **Gander** — 零权限的 Android 文件查看器，主打隐私安全（HN 166 分）。<https://github.com/mokshablr/gander>
- **FIM-Optimizer** — Exact Fisher 优化器，在 44 组噪声数据对比中 43 组击败 AdamW。<https://github.com/zhaohongli678/FIM-Optimizer>
- **Rivet：SQLite 零磁盘 S3 分层存储引擎** — 首个面向 SQLite 的 zero-disk、S3 分层存储引擎。<https://rivet.dev/blog/2026-07-31-how-we-built-the-first-zero-disk-s3-tiered-storage-engine-for-sqlite/>
- **GTK4 SSH-askpass (Zig)** — 用 Zig 编写的 GTK4 ssh-askpass，展示 Zig 在系统工具上的实践。<https://xn--gckvb8fzb.com/a-gtk4-ssh-askpass-in-zig/>
- **DataFusion 十亿级图算法** — 借助 DataFusion 在 10GB 内存内完成十亿级图算法。<https://semyonsinchenko.github.io/ssinchenko/post/datafusion-graphs-cc-2/>
