> **统计周期：2026 年 10 月 24 日—10 月 30 日（北京时间）**

## 🔥 本周热点

1. **Gemini 4 Carbon 聚焦长程工程与网络防御，但先限量开放** — Google 称 Carbon 能持续数日处理复杂工程任务，并在漏洞发现、利用验证和修复 benchmark 上领先；目前仅逐步向 Fairwind Program 中的网络防御者开放，开发者与消费者版本尚未全面上线。SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0% 及内部安全数据均为 Google 厂商 benchmark/声明。[Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)

2. **Genie 4 把世界模型推进到“可听、可改、可持续交互”** — Google DeepMind 发布原生多模态世界模型 Genie 4，可实时生成环境音、音乐与互动对话，并允许用户用自然语言在运行中改变天气、镜头和对象。它已向可信测试者提供研究预览，后续将从 Project Genie 的 Google AI Ultra 用户及部分 Gemini API、AI Studio 合作伙伴开始扩展；效果描述目前主要来自官方演示。[Google DeepMind](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/)

3. **OpenAI 用外部学术协作处理 AI 生成的重大科研主张** — OpenAI 公布模型在调和分析、复杂性理论和量子场论上的三项结果，并采用公开原始输出、组织外部工作组或暂缓发布等不同路径。自然语言证明和部分 Lean 形式化材料已公开，但这些重大结论仍需要学术共同体持续检查，不能把“已形式化”直接等同于影响与解释均已得到共识。[OpenAI](https://openai.com/index/building-scientific-understanding-with-academic-communities/) · [公开仓库](https://github.com/openai/math)

4. **LiteLLM 供应链事件暴露 AI 基础设施的高价值凭据面** — 微软披露，受入侵的 LiteLLM 1.107.0 于 10 月 21 日经 PyPI 和官方容器镜像分发，恶意文件可借 Python 启动钩子执行，即使应用没有导入 LiteLLM；目标包括模型供应商密钥、云凭据、SSH 和浏览器数据。微软警告不要在疑似受影响环境中启动 Python 或 pip，且仅删除包不足以完成恢复。[Microsoft Security](https://www.microsoft.com/en-us/security/blog/2026/10/23/inside-the-litellm-1-107-0-supply-chain-compromise-credential-theft-through-python-startup-hooks/)

5. **AI 经济影响的衡量对象从单体模型转向多 Agent 组织** — DeepMind Institute 提出，个体能力提升会渐进改变工资和任务组合，而 Agent 之间跨过“协调”阈值后，企业规模、市场集中度与就业可能出现突变。文章同时强调，若 AI 引发劳动转型，收入补偿无法替代工作提供的能动性、归属、地位和意义；这是研究框架与调查分析，不是已发生的宏观预测。[DeepMind Institute：智能经济学](https://institute.deepmind.com/essays/the-economics-of-intelligence/) · [工作与福祉](https://institute.deepmind.com/essays/what-is-work-for-human-wellbeing-and-the-value-of-work-in-the-agi-era/)

## 🛠️ 新工具 / 产品发布

- **Google Connected Apps Platform（预览）** — 开发者可通过云端 MCP Server 或 Android AppFunctions 接入一次，再选择把工具发布到 Gemini app、Search 或两者；Connected Console 集中提供注册、测试、审核、发布和流量/延迟/错误监测。[Google](https://blog.google/innovation-and-ai/technology/developers-tools/connected-apps-one-place/) · [开发者文档](https://developers.google.com/connected-apps)
- **Google Docs / Drive 原生 Markdown 协作** — `.md` 文件无需转换即可预览、编辑、评论和保留版本历史，底层文件格式保持不变，便于人类与 Agent 围绕同一份技术文档协作。[Google Developers Blog](https://developers.googleblog.com/preview-edit-and-collaborate-on-markdown-md-files-natively-in-google-docs-and-drive/)
- **Apgar** — Apache 2.0 自托管的 Agent 发布健康监测工具，通过 OpenTelemetry 或 Langfuse trace 对比新版本和生产基线，检测工具错误、重试、循环、成本与延迟回退；不使用 LLM judge，也不存储提示词和补全文本。[GitHub](https://github.com/oimo-ai/apgar)
- **Mainplane** — MIT 许可、Go 编写的自托管 Agent harness，可连接不同模型、消息入口和多台设备，提供共享文件系统、浏览器/电脑操作及细粒度控制。[GitHub](https://github.com/mainplane-ai/mainplane)
- **StoreRouter CLI 0.5.0** — 面向开发者和购物 Agent 的终端工具，可跨已覆盖商店搜索、解析商品页、寻找相似商品与品牌，并支持 JSON 输出和 `jq` 管道；网页 Playground 以 WebAssembly 运行同一 CLI。[项目页](https://storerouter.ai/playground)
- **UserRank** — 由用户自己的 Claude 或 ChatGPT 在本地/会话侧扫描 AI 工具与实践，再分享实践名称和计数的目录及排行服务；使用时仍应先审查插件权限与历史会话访问范围。[项目页](https://app.userrank.ai/)
- **SimReady Central Library** — NVIDIA 汇集 2,000 多个带仿真属性的 USD 资产，供机器人、AI 工厂和数字孪生场景组装；官方展示了 Agent 从中选择资产并经人工审阅构建场景的流程。[NVIDIA](https://blogs.nvidia.com/blog/developers-simulation-frontier-ai-agents/) · [资源库](https://huggingface.co/spaces/nvidia/simready-central)

## 📊 模型更新

- **Gemini 4 Carbon** — 面向长程软件工程与网络防御的前沿模型，首阶段限可信网络防御者使用。官方公布的体验价为每百万输入 token 2 美元、输出 10 美元，缓存输入较输入价低 95%；体验期后计划翻倍。所有能力、安全和内部对比数据均应视为厂商声明。[Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)
- **GPT-6.1 Terra** — 强化视觉理解、电脑操作、写作和编码，现已进入 ChatGPT Work、Codex 与 API（`gpt-6.1-terra`）。标准 API 每百万输入、缓存输入和输出 token 分别为 1、0.05 和 5 美元；Agents’ Last Exam、OSWorld、Terminal-Bench 及事实性结果均为 OpenAI 厂商 benchmark/声明。[OpenAI](https://openai.com/index/introducing-gpt-6-1-terra/)
- **Genie 4** — 可实时生成并接受交互修改的世界模型，加入原生环境音、音乐和对话，面向机器人/Agent 训练环境与互动体验；当前是研究预览而非普遍可用 API，物理一致性和人物表现主要由官方样例展示。[Google DeepMind](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/)

## 💡 趋势观察

- **长程 Agent 的瓶颈正在从单步智力转向协调、验证与发布治理**：Carbon 强调持续数日执行，Apgar监测发布后行为回退，学术工作组负责解释 AI 产出的证明；“做出结果”之后，还需要轨迹、证据和责任链。
- **MCP 正从开发者插件协议变成大型消费入口的分发层**：Google Connected Apps 让一次 MCP/AppFunctions 接入覆盖 Gemini 和 Search，意味着工具发现、OAuth、审核与品牌归属将成为 Agent 产品的新应用商店能力。
- **Agent 基础设施进入软件供应链攻击主战场**：模型网关天然聚集 API 密钥、云身份和路由数据，LiteLLM 事件说明依赖锁定、构建来源验证、短期凭据与环境隔离应成为默认配置。
- **世界模型与物理仿真的边界继续靠近**：Genie 4 从生成视频走向实时可操控世界，Omniverse 案例则让 Agent 编排确定性物理、渲染和工程求解器；短期更现实的路径可能是生成模型与可验证模拟器混合，而非完全替代后者。[Google DeepMind](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/) · [NVIDIA](https://blogs.nvidia.com/blog/developers-simulation-frontier-ai-agents/)
