AI 周报 — 2026年10月第1周

统计周期：2026 年 9 月 26 日—10 月 2 日（北京时间）

🔥 本周热点#

  1. GPT-6.1 Sol 发布，前沿模型竞争继续转向“每项任务成本” — OpenAI 将 GPT-6.1 Sol 定位为 Sol 系列升级版，API 标准输入、缓存输入和输出价格分别为每百万 token 2 美元、0.10 美元和 10 美元。官方称其在编码、电脑操作、专业工作和科学任务上接近 GPT-6 Astra，同时维持明显更低的任务成本；相关 benchmark 均为厂商声明，仍需独立评测验证。OpenAI

  2. OpenAI 推出可长期后台工作的 Dots — Dots 是由 GPT-6 Astra 驱动、拥有独立云电脑的常驻 Agent，可连接 4,000 多个应用，并通过 ChatGPT、Slack 或 Teams 与用户协作。产品强调后台主动研究、跨渠道上下文、应用权限、Custom Rules 与高风险动作审批；OpenAI 同时提醒，Dots 仍可能犯错，重要工作需要人工复核。OpenAI

  3. Agent 安全从模型提示词下沉到独立运行时和硬件监控 — NVIDIA 发布 Open Agent Safety Platform：开源 OpenShell 在 Agent 工作负载之外执行沙箱、凭据和访问策略，Sentry 则计划借助 BlueField-4 DPU 从带外监控并隔离越界行为。平台性能和“毫秒级隔离”等结论属于厂商声明。NVIDIA Newsroom · OpenShell 技术说明

  4. 开放权重模型的网络攻击能力与可移除护栏引发警报 — Anthropic 对 Z.ai 的 GLM-5.3 进行隔离环境评测，称其端到端漏洞利用能力接近 Claude Mythos Preview，且简单方法可在模拟测试中绕过其防护；文章也援引 NIST CAISI 对该模型网络能力的独立评估。具体成功率和对比结果来自 Anthropic 测试，应视为机构/厂商评测，而非普遍场景结论。Anthropic

  5. Agent 工程关注点从“能否完成”转向“路径是否可控、可观测、可验证” — 本周的新项目分别覆盖确定性数据流护栏、执行轨迹、语义代码审查和长期记忆；共同目标是让 Agent 的中间行为能被约束、复盘与验收，而不只检查最终答案。OpenAPPA · NeMo Relay · Perspica · Recalld

🛠️ 新工具 / 产品发布#

  • OpenAI Dots — 拥有独立云电脑、应用连接和长期上下文的常驻 Agent；支持后台工作、Activity View、动作审批及组织级 specialist dots 预览。OpenAI
  • NVIDIA OpenShell 0.1.0 — 开源 Agent 运行时，通过 Gateway、Supervisor 与 Sandbox 在工作负载之外执行文件、进程、网络、API 操作和凭据策略，并生成 OCSF 审计记录。NVIDIA · GitHub
  • OpenAPPA — MIT 许可的确定性 Agent 护栏，以 audience × trust 标签追踪跨工具调用的数据流，并可返回脱敏、单次授权或隔离子 Agent 等补救方案。其“0% 攻击成功率”等 benchmark 为项目方声明。官网 · GitHub
  • NeMo Relay — Agent 执行观测层，可生成 ATOF 事件流、ATIF 逐步轨迹以及带 OpenInference 标注的 OpenTelemetry spans，用于分析工具错误、重试、耗时和 token 使用。NVIDIA
  • Perspica — 本地语义 diff 工具，以 tree-sitter 分析重命名、移动、签名变化和未更新调用，支持 TypeScript、Python、Rust、Go、Java、Scala 与 C；LLM 总结是可选项。GitHub
  • Recalld — 面向 Agent 的托管长期记忆层，提供 add、recall、search 三类 API 和 MCP 接口，可抽取并更新事实，再只返回与问题相关的记忆。LoCoMo 准确率和 token 节省数据为项目方自测声明。官网 · 评测仓库
  • DOCA Agent Skills — 面向 BlueField/DOCA 开发的 SKILL.md 集合，包含真实 API 签名、硬件能力要求、构建约束和预检流程；“65 个提示中检查项从 19% 提升至 100%”为 NVIDIA 自测声明。NVIDIA · GitHub
  • TensorRT Model Connect — 面向 TensorRT 的开源 C++ 模型参考实现集合，采用模型家族隔离、可逆变更和 GPU 验证来支持 Agent 并行开发；NVIDIA 称其 7 月公开版本覆盖 128 个模型家族。NVIDIA · GitHub

📊 模型更新#

  • GPT-6.1 Sol — 已向 ChatGPT Work、Codex 的部分付费与组织用户开放，并通过 API 以 gpt-6.1-sol 提供。OpenAI 报告其在 DeepSWE 1.1、GDP.pdf、AutomationBench、OSWorld 2.0 与 Terminal-Bench Science 上较 GPT-6 Sol 有不同程度提升；这些分数、竞品成本比较及事实错误率均为厂商声明。OpenAI
  • GLM-5.3 / GLM-5.3-Flash — 本周关注重点不是常规能力榜单，而是开放权重模型的网络攻击能力扩散。Anthropic 称 GLM-5.3 在其 ExploitBench 测试的 410 次尝试中完成 50 次端到端利用，并披露护栏可被绕过或通过权重编辑显著削弱；这是 Anthropic 的安全评测结论。Anthropic

💡 值得关注的趋势#

  • 常驻 Agent 正取代一次性会话成为产品形态：独立计算环境、跨应用上下文、后台执行与主动发现任务都被打包进 Dots；产品竞争将扩展到记忆、权限、身份和监督体验。OpenAI
  • 安全控制正在移出模型上下文：OpenShell 和 OpenAPPA 都把核心策略放在 Agent 无法通过提示修改的外部执行层；一个侧重沙箱与 API/凭据控制，另一个侧重跨步骤数据流。OpenShell · OpenAPPA
  • 可观测性将与最终任务分数同等重要：NeMo Relay 展示了如何把模型调用、工具调用、错误、重试、耗时和 token 消耗串成可审计轨迹；“答对”不再能掩盖低效或危险路径。NVIDIA
  • 为 Agent 设计的软件项目强调隔离与机器可验证契约：TensorRT Model Connect 和 DOCA Skills 都不依赖更复杂的提示编排，而是通过任务隔离、明确验收标准、真实 API 合约和硬件验证降低错误扩散。TensorRT Model Connect · DOCA Skills
