AI 周报 — 2026年11月第1周

统计周期：2026 年 10 月 31 日—11 月 6 日（北京时间）

🔥 本周热点#

  1. GPT‑6 Cyber 把网络安全 Agent 推到“关键能力”级别 — OpenAI 发布面向授权安全研究的专用模型，可发现、验证漏洞并生成修复建议。官方称其 ExploitGym 得分从 GPT‑5.6 Cyber 的 32.1% 提升至 48.5%，并在无部署提示时有 99.93% 的测试未越出授权范围；这些均为 OpenAI 厂商 benchmark/声明。模型被按其 Preparedness Framework 归为网络安全 Critical，深度利用能力通过受控的 Daybreak Red 提供，而非普遍开放。OpenAI

  2. 948 条 Linux 提权路径展示了漏洞研究流水线的规模，也暴露新瓶颈 — OpenAI 的隔离实验管线从 2,308 个候选中动态复现 1,724 个漏洞，生成 948 个本地提权 exploit 和候选补丁，总 API 成本约 121 万美元；最终仍由人类研究员审查并向维护者报告。数字与成本均为 OpenAI 厂商研究声明，但“发现不再稀缺、验证与修补成为瓶颈”的工程变化值得关注。OpenAI

  3. 生成式视频进入原生 15 秒与多轮编辑阶段 — Google 将 Gemini Omni 1.2 Flash 全面提供给 Gemini API 和企业平台，支持 3—15 秒原生生成、参考图/短视频/音频条件以及对同一片段的多轮修改；官方定价为 720p 每秒 0.07 美元，称较 1.1 降低 30%。一致性、口型和镜头表现来自 Google 厂商演示/声明，仍需按具体素材验证。Google

  4. OpenAI 收购 Pierre，编码 Agent 的竞争延伸到 Git 与代码审阅基础设施 — Pierre 的 Trees、Diffs 已用于 Codex，Code Storage 则提供 Git 兼容的代码存储和历史追踪。交易尚待监管批准；OpenAI 表示相关开源项目会保持开源，并计划把 Code Storage 能力带入 Codex。OpenAI

  5. 评测从“会回答”转向“能把生活事务办完” — OpenAI 发布 LifeVal，基于时间使用调查及 3,995 人代表性调查，覆盖照护、健康、教育、家庭行政、财务、购物和政府服务等实际流程。页面展示的高分属于 OpenAI 自建评测和厂商声明，但它体现了浏览器、电脑操作、连接器及行动完成度正在成为个人 Agent 的核心衡量对象。OpenAI

🛠️ 新工具 / 产品发布#

  • Images 2.6 — 在 ChatGPT、Codex 与 API 中提供更快生成、GIF、局部标注编辑、SVG 导出和复杂度参数。OpenAI 称生成速度提高 50%，API 提供偏速度的 Flare 与偏质量/编辑一致性的 Sunburst；速度与质量数据为厂商声明。OpenAI
  • Gemini Omni 1.2 Flash — 可生成和多轮编辑最长 15 秒的视频，接受图像、短动作与音频参考，输出带 SynthID；已在 Gemini API 和企业平台 GA，并进入 Flow、Vids、Gemini app 等产品。Google
  • Momentic / Mo — 面向 Web、iOS 和 Android 的 AI QA 工具，可用自然语言 YAML 描述端到端流程，在 CI 中运行、保留截图与 trace、分类故障并提出测试修复；其生产数据和客户提效数字属于厂商声明。Momentic
  • fastbrowse — MIT 许可的浏览器自动化 Agent，可本地或托管运行；完成事实读取时返回逐字页面引文，支持 schema 校验、作用域 secret、不可逆动作授权门和运行回放。项目页 · GitHub
  • SynapsCLI — Rust 编写的终端原生 Agent runtime，提供交互聊天、并行 Agent 编排、监督机制与 MCP 集成，采用 Apache-2.0 许可。GitHub
  • Knemora — MIT 许可、local-first 的开源“第二大脑”，围绕本地模型、知识库和知识图谱组织个人资料，项目仍处 alpha 阶段。GitHub
  • Penthera — 面向应用和 AI 编码工具的离线安全 Agent，覆盖依赖、secret、SBOM 与供应链检查，并提供 CLI、GitHub Action、MCP 和编辑器技能；项目公开 benchmark 仍应结合独立测试判断。GitHub
  • Omniverse Agent Skills / Houdini MCP — NVIDIA 展示了 Agent 调用 Omniverse、Isaac Sim、Houdini 和工程求解器生成可编辑 3D 资产、数字孪生及机器人仿真；示例由开发者指导和审阅，不等同于全自动生产能力。NVIDIA · Houdini MCP

📊 模型更新#

  • GPT‑6 Cyber — 专为授权漏洞研究、利用验证与修复开发训练，通过 Daybreak 分层提供。ExploitGym 48.5%、Web 渗透评测 40.3% recall、越界规避率等均为 OpenAI 厂商 benchmark；高能力伴随 IP allowlist、误用监测、沙箱和人工监督要求。OpenAI · System Card
  • Gemini Omni 1.2 Flash — 原生支持最长 15 秒视频、逐秒时长控制、多轮对话编辑和 1080p/4K 放大工作流；官方称价格较上一代低 30%，一致性与自然语音更强，均属 Google 厂商声明。Google
  • GPT‑Image‑2.6 Flare / Sunburst — Flare 偏低延迟和版式，Sunburst 偏高质量与连续编辑一致性；OpenAI 称低质量档 Flare 最快约 6 秒、整体生成快 50%，均为厂商 benchmark/声明。OpenAI

💡 趋势观察#

  • 网络安全 Agent 正从辅助审阅变成“发现—复现—利用—补丁”的闭环系统：这会同时压缩防守与攻击的时间窗口。未来关键不只是模型分数，而是授权边界、隔离执行、协调披露、补丁吞吐与审计证据。
  • 生成媒体竞争转向可编辑资产，而不只是一次性样片：15 秒原生视频、多轮修改、SVG/GIF、参考一致性和复杂度控制，都在把模型嵌入广告、设计和内容生产流水线。
  • “可核验执行”成为 Agent 工具的新卖点：fastbrowse 强调引用和 secret 隔离，Momentic 保留截图与 trace，安全管线保存 PoC 和补丁；可回放证据正在替代一句“任务已完成”。
  • 编码 Agent 开始重塑版本控制本身：Pierre 收购、Pando 与并行 Agent 工作方式表明，分支数量、diff 审阅、代码历史和合并决策都需为机器参与者重新设计。OpenAI · Scaling Git
  • 物理世界工作流更可能走“Agent 编排确定性工具”路线：Omniverse 案例中，模型负责规划和调用，物理引擎、CAD、求解器和人类审阅负责约束与验证；这比纯生成模型独立替代工程仿真更接近当前可落地形态。NVIDIA
