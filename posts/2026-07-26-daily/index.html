🔥 今日高光

  1. 深度研究智能体学会『递归自我改进』：AREX 抓住『找答案贵、验答案便宜』这一不对称性——先验证中间结果，再用已部分验证的状态引导下一步 refine，124 赞断层登顶本批日榜。
  2. 空间认知改用『画』的来考：Show, Don’t Tell 指出坐标/选项/文字的答题接口对图像生成模型天生错配，干脆让模型直接在像素上标点、画路径来展示空间智能。
  3. Coding Agent 评测硬刚数据污染：腾讯 WorkBuddy Bench 每道题都从真实 commit / PR 反向工程再改写成口语化角色扮演请求，让题面无法被网上原文检索命中。

  5. 把 Agent 直接写成 Python 对象：NVIDIA NOOA 让方法=动作、字段=状态、docstring=提示词、类型注解=契约；方法体写 ... 就在运行时交给 LLM 补全，其余保持确定性 Python。

📄 论文速递

AREX：面向递归自我改进的深度研究智能体 —— 利用『发现难、验证易』的不对称性，让研究智能体在内循环里验证中间结果，并用部分验证状态引导后续 refine，而非单纯搜索更久（124 赞，本批最高）。https://arxiv.org/abs/2607.21461

ReferTrack：先指代、再跟踪的具身视觉跟踪 —— 针对 VLA 策略里 CoT 在抽象空间隐变量中推理、难监督且与图像检测弱对齐的问题，改为『先从单目前视相机选定目标、再跟踪』的显式接地范式（48 赞）。https://arxiv.org/abs/2607.20061

Visual Contrastive Self-Distillation（VCSD） —— 追问 on-policy 自蒸馏能否同时去掉『特权答案』和『视觉证据』两种非对称信息，提出把图像内容移除转成输入条件，构造纯靠输入条件驱动的更简洁自蒸馏（41 赞）。https://arxiv.org/abs/2607.21556

Show, Don’t Tell：用生成像素而非 LLM 文本评估空间认知 —— 指出现有空间推理基准要坐标/选项/文本，与图像生成模型存在答题接口错配，改让模型用指点、标记、绘制在连续视觉场景里作答（34 赞）。https://arxiv.org/abs/2607.21072

Tencent WorkBuddy Bench：抗污染的多领域 Coding-Agent 基准 —— 覆盖 Code/Web/Office/Security 四域，每道题从真实 commit/PR/业务场景反向工程、重写为口语化角色扮演请求，使题面无法被网络原文检索恢复，附跨模型排行榜（20 赞）。https://arxiv.org/abs/2607.20911

NVIDIA NOOA：原生 Python 面向对象智能体 —— 把智能体建模为一个 Python 对象：方法即动作、字段即状态、docstring 即提示词、类型注解即契约；方法体为 ... 时运行时由 LLM agent loop 补全，普通方法体仍是确定性 Python（19 赞）。https://arxiv.org/abs/2607.20709

SANA-Video 2.0：带注意力残差的混合线性注意力高效视频生成 —— 5B/14B 统一架构的混合视频 DiT，用门控线性注意力做 O(N) 主体混合、3:1 穿插门控 softmax 锚点补回全秩交互，单 GPU 生成至 720p 视频且匹配 full-softmax 质量（18 赞）。https://arxiv.org/abs/2607.21553

LLMs Get Lost in Evolving User Intent —— 真实交互里用户意图是边聊边披露、修正、重塑的，但 LLM 仍多在单轮、完全指定的设定下评测/训练；论文构建框架考察模型能否随对话追踪并执行不断演化的用户意图（17 赞）。https://arxiv.org/abs/2607.20734
